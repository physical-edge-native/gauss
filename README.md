# gauss

Split control versus central control of robots, compared as a pure question of model
architecture, at the size of industrial robots. Part of the
[Physical-Edge Native Architecture](https://physical-edge-native.github.io/) project.

**Status: just started. Nothing here yet.**

The sister repository [erg](https://github.com/physical-edge-native/erg) makes the same comparison
on a cheap four-legged robot built from hobby parts. Differences that matter at industrial size may
not show on a small, cheap robot, so the architecture comparison is kept here, separately.
We make no claim that split control is better than central control; the comparison is the result.
